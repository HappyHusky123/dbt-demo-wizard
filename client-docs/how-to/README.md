# How-to guides

Recipes for a goal you already have. If you do not yet know what you want to accomplish, start with
[project context](../explanation/project-context.md).

| Guide | Goal |
|---|---|
| [Add a mart model](./add-a-mart-model.md) | Put a new reporting model into `DATA_VIZ` |
| [Add a staging model](./add-a-staging-model.md) | Bring a new source table into `STAGE` |
| [Run the project](./run-the-project.md) | Build, test, and control what the build costs |
| [Write documentation](./write-documentation.md) | Add to `client-docs/` without creating a second copy of a fact |

Each guide states the steps and links out for the reasoning. Where a guide and an
[ADR](../adr/) disagree, the ADR wins.
